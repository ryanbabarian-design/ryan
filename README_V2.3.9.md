# 하나금속 제안관리 V2.3.9 — 최종 4단계 결재

최종 결재선:

**담당(자동작성) → 부서장 → 해당부서 임원 → 대표이사**

## 적용 효과
- 주관부서 단계 비활성화
- 기존 대표이사 계정 연결 보존(대표이사 step ID 유지, 순서만 4번으로 변경)
- 부서장/해당부서 임원은 부서별 지정
- 대표이사는 전체 부서 공통 지정
- 상세화면/인쇄 결재란 4칸 표시
- 이메일 Cron/Resend 설정 그대로 사용
- 동일 결재자 연속단계 자동승인(V2.3.7) 유지
- 과거 실데이터 삭제 없음

## 적용 순서
1. Supabase SQL Editor → New query
2. `sql/V2.3.9_최종4단계결재_실행.sql` 전체 실행
3. 결과가 `1 담당 / 2 부서장 / 3 해당부서 임원 / 4 대표이사`인지 확인
4. GitHub에 `index.html`, `js/app.js`, `js/core.js`, `js/print.js`, `js/services/store.js` 덮어쓰기
5. 기존 `js/config.js`는 유지
6. Commit 후 1~3분 뒤 Ctrl+F5

기존 테스트 제안은 사용자가 사이트에서 삭제해도 되며, SQL은 과거 실데이터를 삭제하지 않습니다.
