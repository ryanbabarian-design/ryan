# 하나금속 제안관리 V2.3.15

## 주요 변경

- 제안 작성 화면에 `제안자 예상 효과금액(원)` 추가
- 심사 화면에서 제안자 예상금액을 읽기전용으로 확인하고 `심사 확정 효과금액(원)`을 별도 확정
- 0점/미심사 포상금 5,000원 오류 수정
  - 미심사 또는 0점: 0원
  - `건수처리`를 명시적으로 선택한 경우만: 5,000원
  - `채택` + 점수구간: A/B/C/D 기존 기준
- 해당부서 임원 승인 후 대표이사 결재 자동활성화 중단
- 시스템 관리자 메뉴에 `대표이사 일괄상신` 추가
- 심사완료 + 임원승인 제안만 선택 상신
- 대표이사 결재함에 선택 `일괄승인` 추가
- 대표이사 반려는 기존처럼 건별 처리
- 여러 건 일괄상신 시 대표이사에게 요약 이메일 1통 발송
- 이메일 로그인 안내(결재 아이디/최초 발급 비밀번호 1111) 유지

## 적용 순서

### 1. Supabase SQL

SQL Editor → New query → 아래 파일 전체 실행:

`sql/V2.3.15_효과금액_대표이사일괄상신_실행.sql`

마지막 결과에서 아래 RPC가 모두 true인지 확인:

- ceo_candidate_rpc
- ceo_submit_rpc
- ceo_batch_approve_rpc
- secure_approval_rpc
- inbox_rpc

### 2. GitHub Pages 파일 덮어쓰기

저장소 루트에 아래 파일을 덮어쓰기:

- `index.html`
- `js/app.js`
- `js/core.js`
- `js/print.js`
- `js/services/store.js`

`js/config.js`는 절대 삭제/덮어쓰기 하지 않습니다.

Commit 후 1~3분 뒤 브라우저에서 Ctrl+F5.

### 3. Supabase Edge Function 업데이트

Supabase → Edge Functions → `approval-email` → Code에서 기존 `index.ts` 전체를 아래 파일 내용으로 교체:

`edge-functions/approval-email/index.ts`

그 다음 `Deploy updates`.

기존 Resend Secret과 Cron은 그대로 사용하므로 다시 만들 필요 없습니다.

## 최종 업무 흐름

1. 제안자가 제안내용 + 예상 효과금액 작성
2. 담당 자동작성
3. 부서장 승인 → 해당부서 임원에게 즉시 알림
4. 해당부서 임원 승인
5. 관리자가 심사결과/점수/최종 효과금액 확인 후 `업무상태=심사완료` 저장
6. 관리자 `대표이사 일괄상신` 메뉴에서 여러 제안 선택 후 상신
7. 대표이사에게 상신목록 요약메일 1통 발송
8. 대표이사 결재함에서 개별검토 또는 선택 일괄승인

## 확인 테스트

- 점수 0 + 미심사 → 포상금 0원
- 심사결과 건수처리 → 포상금 5,000원
- 임원 승인 직후 대표이사 결재함에 자동으로 나타나지 않음
- 심사완료 후 관리자 일괄상신 목록에 나타남
- 2~3건 선택 상신 시 선택한 건만 대표이사 결재함에 표시
- 대표이사 일괄승인 시 선택한 건만 승인
- 대표이사 이메일은 일괄상신 건별 메일이 아니라 요약메일 1통
