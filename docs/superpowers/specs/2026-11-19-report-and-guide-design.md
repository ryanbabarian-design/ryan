# 실적 엑셀·부서 집계·제안제도 안내 (V2.9.15)

## 목적

실적 보고서의 세로 인쇄와 압연/압연팀 분리 집계를 수정하고 직원이 평가 흐름을 바로 확인하게 한다. 기존 사이트의 직접 수정·배포 요청을 이어 실행한다.

## 결정과 범위

- 관리부 제출요약은 A4 가로. 기존 로고·핵심 수치·집계 근거를 유지하고 전체 부서를 두 단으로 표시한다. 상세 3개 시트의 가로 인쇄·수식·필터·고정행을 유지한다.
- `압연`, `압연팀`은 공통 집계명 `압연`으로 연결한다. 기존 가공/압출인발/공무 명칭 통합을 유지한다. `연천압연팀`과 불확실한 옛 조직명은 합치지 않는다.
- 대시보드·접수 필터·관리 목록·실적·엑셀이 공통 정규화 함수를 사용하고, 과거 별칭 URL의 선택값도 정상 표시한다. 원본 부서와 권한의 부서 비교는 바꾸지 않는다.
- 제안제도 안내는 상단 메뉴, 대시보드, 작성 화면 평가란에서 같은 대화상자로 연다. 작성 내용·이미지·필터를 보존하고 키보드와 모바일에서 닫기/복귀가 가능해야 한다.
- 안내 문구는 현재 코드에 근거한다. 2차 50~64점은 후보이며 임원 승인 후 3차 심사에서 확정한다. 실제 심사위원, 기록 입력자, 대표 결재자를 구분한다. 심사 인정과 대표 승인·포상 지급을 구분한다.

## 검토한 방식

- 엑셀 방향만 바꾸면 부서 생략과 과도한 여백이 남으므로 요약 배치를 함께 조정한다.
- 부서명 끝의 '팀'을 일괄 제거하면 별도 조직을 합칠 수 있어 확인된 쌍만 통합한다.
- 안내 전용 이동 페이지는 작성 중 초안을 잃을 수 있어 같은 화면의 공통 대화상자를 선택한다.

## 검증

공통 집계 회귀, OOXML 인쇄 설정·수식 참조, 운영자료 전후 합계, 모바일·키보드·초안 보존을 검증한다. 운영 데이터 쓰기나 실제 결재는 실행하지 않는다.
