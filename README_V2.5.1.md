# V2.5.1 관리자 1차 평가 수정

## 변경사항
- `심사결과 = 미심사`이고 2차 평가 전인 제안은 시스템 관리자만 1차 평가를 입력/수정할 수 있습니다.
- 일반 사용자/결재자는 1차 평가 수정 권한이 없습니다.
- 관리자 목록에 `1차평가` 상태(`미입력`, `완료 N점`)가 표시됩니다.
- 관리자 심사 화면에 `1차 평가 저장` 버튼이 추가됩니다.
- 1차 평가를 저장해도 심사결과/2차평가/포상금은 변경되지 않습니다.
- 2차 평가 완료 또는 대표이사 상신 이후에는 1차 평가 수정이 잠깁니다.

## 적용 순서
1. Supabase SQL Editor에서 `sql/V2.5.1_관리자_1차평가_수정.sql` 실행
2. GitHub에 `index.html`, `js/app.js`, `js/services/store.js` 덮어쓰기
3. 배포 후 `Ctrl + F5`
