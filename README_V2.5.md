# 하나금속 제안관리 V2.5 — 1차·2차 평가 시스템

## 최종 업무 흐름

`제안 작성 + 1차 자기평가 → 부서장 승인 → 해당부서 임원 승인 → 심사위원회 2차 공동평가 → 대표이사 일괄상신/승인`

### 1차 평가
- 제안서를 올리는 사람이 제출 전에 반드시 작성합니다.
- 업로드된 `2. 2026년 제안서 채점평가 - 복사본.xlsx`와 동일한 평가표를 화면에 표시합니다.
- 독창성×2, 노력도×2, 실현성×1, 응용범위×1, 지속성×1, 유형효과×3.
- 각 항목 1~10점, 환산 총점 100점.
- 1차 점수는 **참고용**이며 최종 점수에는 직접 합산하지 않습니다.

### 부서장 / 해당부서 임원
- 제안내용과 1차 평가표를 읽기 전용으로 확인합니다.
- 점수 수정은 불가합니다.
- 부서장이 승인하면 임원, 임원이 승인하면 2차 평가대기로 전환됩니다.

### 2차 평가
- 심사위원별 개별 점수 입력 방식이 아닙니다.
- **심사위원들이 한 곳에 모여 같은 평가표 1부를 공동 작성**합니다.
- 2차 평가의 환산 총점이 최종 심사점수입니다.
- 2차 평가 완료 시 심사결과·최종 효과금액·포상금이 확정됩니다.

### 대표이사
- 2차 평가/심사완료 건만 기존 `대표이사 일괄상신` 목록에 들어갑니다.
- 대표이사는 1차/2차 평가를 모두 확인한 뒤 기존 방식으로 승인합니다.

## 설치
1. Supabase SQL Editor → New query → `sql/V2.5_1차2차평가_실행.sql` 전체 실행.
2. GitHub에 `index.html`, `js/app.js`, `js/services/store.js` 덮어쓰기.
3. 기존 `js/config.js`는 절대 삭제/수정하지 않기.
4. Commit 후 1~3분 뒤 사이트에서 `Ctrl+F5`.

## 정상 확인
SQL 실행 결과에서 아래가 모두 `true`면 됩니다.
- `evaluation_total_rpc`
- `second_evaluation_rpc`
- `first_evaluation_column`
- `second_evaluation_column`
