# 하나금속 제안관리 V2.0 통합 운영관리

기존 GitHub Pages + Supabase 제안관리 시스템을 그대로 유지하면서 운영관리 기능을 확장한 V2.0입니다.
기존 제안자료, 직원명단, 사진, 관리자 계정 및 `js/config.js`의 Supabase 연결정보는 삭제하거나 초기화하지 않습니다.

## V2.0 주요 기능

- 진행상태 타임라인: 접수 → 심사중 → 심사결과 → 시행중 → 실시완료 → 포상지급
- 장기 미심사(7일 이상), 시행 지연(채택 후 30일 이상) 자동 표시 및 클릭필터
- 조회연도와 연동되는 전체제안 / 심사대기 / 채택 / 실시완료 KPI
- 연도별 부서 목표 등록 및 목표달성률
- 제안자 개인실적: 건수, 채택률, 순위, 누적점수, 포상금, 효과금액
- 우수제안 TOP 10: 점수 / 효과금액 / 포상금 기준 전환
- 효과분석: 투입비용, 포상금, 효과금액, 순효과, ROI
- 유사제안 TOP 5 및 유사도 표시(외부 AI API 미사용)
- 관리자 설정형 전자결재 단계 및 제안별 승인/반려 기록
- 연간/월간 운영보고서 화면, CSV 다운로드, 브라우저 인쇄/PDF 저장
- 관리자 변경이력: 심사/점수/포상/실시/효과/제안내용 변경 및 삭제기록
- 제안서 인쇄 시 전자결재 진행결과 자동 표시
- 기존 사진 개별삭제 및 Storage 자동 정리 기능 포함

## 설치 순서

### 1. Supabase SQL 적용

Supabase → SQL Editor → New query에서 `sql/V2.0_통합업데이트_실행.sql` 전체를 붙여넣고 Run 합니다.

이 SQL은 다음 기능을 추가합니다.

- `proposal_image_cleanup`
- `proposal_audit_logs`
- `proposal_status_history`
- `department_goals`
- `approval_steps`
- `approval_records`
- 관련 Trigger / RLS / 권한 / 기본 전자결재 단계

기존 `proposals`, `employees`, `admins`, Storage 데이터는 초기화하지 않습니다.
기존 제안자료에는 현재 상태를 기준으로 타임라인을 자동 보완하고, 기본 전자결재 레코드를 생성합니다.

SQL 마지막 결과에 위 6개 객체가 행으로 표시되면 적용 확인이 가능합니다.

### 2. GitHub 파일 업로드

GitHub 저장소 → Add file → Upload files에서 이 패키지의 다음 항목을 덮어씁니다.

- `index.html`
- `assets` 폴더
- `css` 폴더
- `js` 폴더

**중요:** 이 배포 패키지에는 `js/config.js`가 없습니다. 현재 GitHub에 있는 `js/config.js`는 삭제하지 마세요.

Commit changes 후 GitHub Pages 배포를 기다리고 `Ctrl + F5`로 새로고침합니다.

## 첫 운영 설정

관리자 로그인 후 다음 순서로 설정하면 됩니다.

1. 관리자 → `부서 목표관리`: 연도/부서별 연간 목표건수 등록
2. 관리자 → `전자결재 설정`: 담당/팀장/공장장/대표이사 등 실제 결재선 확인·수정
3. 관리자 → 제안 심사: 제안별 심사 및 전자결재 처리
4. 관리자 → `관리자 변경이력`: 주요 변경내역 확인

## 보고서

대시보드 → `월간/연간 운영보고서`에서 연도와 월을 선택할 수 있습니다.

- 연간 전체: 해당 연도 전체 실적
- 특정 월: 해당 연도 해당 월 실적
- CSV 저장
- 인쇄 / PDF 저장

## 운영상 참고

- V2.0 적용 이전의 과거 관리자 변경이력은 원본 데이터만으로 완전히 복원할 수 없으므로, 변경이력은 V2.0 적용 이후부터 정확히 축적됩니다.
- 기존 제안의 상태 타임라인은 현재 DB 상태를 기준으로 최초 보완됩니다.
- 유사제안 기능은 외부 AI 서비스가 아니라 현재 제안 DB의 제목/문제점/개선방안 텍스트 유사도를 계산합니다.
- `service_role` 또는 Secret key는 절대 GitHub에 올리지 마세요. 기존 Publishable key가 들어 있는 `js/config.js`만 그대로 유지합니다.
